RISC-V assembly program that reads a text file, computes the frequency of each ASCII character, calculates the file’s Shannon entropy, and estimates the minimum lossless compressed size. Built for the RARS simulator using system calls for file I/O, a 100 KB input buffer, 128-entry character-count array, and fully integer arithmetic. Implements an approximate log2 via successive division and scaled fixed-point values (thousandths) to preserve precision, with a minimum entropy floor of 1 bit per symbol. Outputs original size and estimated compressed size in bytes.
